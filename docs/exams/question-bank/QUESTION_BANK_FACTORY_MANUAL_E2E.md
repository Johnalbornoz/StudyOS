## 1. Open Question Bank Health

1. Sign in as the platform admin and go to **Consola de administración → Banco de preguntas** (`/dashboard/admin/question-bank`).
2. **Expect:**
   - One row per published exam version, grouped by family (PAA, PISA, AICE, CAMBRIDGE, IB, ICFES).
   - Columns: Examen · Versión · Catálogo · Estructura · Práctica · Simulacro reducido · Simulacro completo · Completo calibrado · Activas · Piloto · Revisión · Salud de cobertura.
   - No row shows "sin calcular" (snapshots exist).

## 2. Select PAA

1. Click **Ver** on *PAA (Prueba de Aptitud Académica)*.
2. **Expect:**
   - Subtitle `V2.1 PAA revisada (guía 2021) · PAA · contenido DEV_CERT_FIXTURE`.
   - "Generación: admitida".
   - "Unidades: por pregunta".
   - Official content 0 %.

2. **Expect** 20 cells, every one *Insuficiente · P1*. For example, Matemáticas · Álgebra:

## 6. Queue a bounded generation batch

1. In *Matemáticas — huecos del blueprint*, row *Álgebra*, click **Generar lote pequeño (3)**.
2. **Expect** the message "En cola: se procesa en segundo plano."
3. Click it again immediately. **Expect** "Ya había una solicitud abierta para esta celda." (idempotent: no second request).
4. Open **Operaciones de generación** (`/dashboard/admin/question-bank/operations`). **Expect:**
   - One request for `matematicas · paa.mat.algebra`, P1, MANUAL_SMALL_BATCH.
   - Status RUNNING, then COMPLETED within about 2 minutes.
   - Budget line `N / 10 llamadas`, with N ≤ 6 for this run.
5. Optional, reading path (uses the independent validator): repeat on *Lectura · Inferencia*. Only do this if the budget line still shows ≥ 4 calls left.

## 7. Observe lifecycle

1. On the operations page, under *Candidatas generadas (últimas)*, **expect** for the algebra request ≤ 3 candidates (plus repaired v2 rows if a repair happened), each with a lifecycle:

   - **Rechazada**: with findings, e.g. `DUPLICATE_TEMPLATE_OTHER_NUMBERS`, `KEY_NOT_VERIFIED`.
   - **Reemplazada** v1 + **Piloto** v2: a repaired candidate.
2. **Expect** in *Ejecuciones de la fábrica* one MANUAL run: Estado COMPLETED (or STOPPED_* with a reason), Llamadas IA ≤ 6, tokens and cost filled, aceptadas / rechazadas / reparadas consistent with the candidates.
3. **Expect** no candidate is *Activa* (generated content always pilots first).
