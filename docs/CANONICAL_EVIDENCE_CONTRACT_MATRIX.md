## Special audit: does REINFORCE corrupt Practice qualification?

**No — verified PASS.** `qualifyEvidence`'s PRACTICE branch and the real evidence adapter's `resolveActivityType` both key exclusively off `metadata.activityType` (== `PRACTICE` for a REINFORCE-overlay session, since REINFORCE reuses the `topic_practice` quiz mode). `metadata.canonicalActivityType` (== `REINFORCE`) has no reader anywhere in the qualification path. The Section 10 regression sequence (`Practice 100, Prove 50, Practice 67, Practice 100`) is replayed exactly in `tests/unit/audit-canon-v2-practice-consistency.test.ts` and confirms the final Practice 100% row qualifies normally. **The real risk is forward-looking**: this safety currently exists only because no code reads `canonicalActivityType` for qualification — it is not a designed invariant with a guard test protecting it from a future regression. The audit suite's `REGRESSION GUARD` test now provides that protection going forward.
