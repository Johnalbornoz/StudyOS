## Project Philosophy

**Core Principles:**
1. **Never reset student knowledge** — Every lesson builds on previous learning
2. **Every mistake becomes evidence** — Errors drive future study plans
3. **Real exams calibrate system** — Actual results improve next cycle
4. **Language-independent mastery** — Switch languages without losing knowledge
5. **Afternoon study focus** — Designed for after-school preparation
6. **Cumulative learning** — Current + debt + prerequisites + spaced review
